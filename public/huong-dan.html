📘 Hướng dẫn vận hành Mino (M1 MVP)

Hệ thống bán hàng COD cho một cửa hàng với cơ sở dữ liệu PostgreSQL và phiên quản trị bảo mật.

1

Khởi tạo môi trường & tài khoản chủ shop

  1. Sao chép .env.example thành .env và điền DATABASE_URL cùng SESSION_SECRET ngẫu nhiên tối thiểu 32 ký tự.
  2. Khởi động PostgreSQL, chạy migration và nạp dữ liệu mẫu ban đầu:
docker compose up -d db
npm run db:migrate:dev
npm run db:seed
npm run admin:create
npm run dev
🔐 Hệ thống không có tài khoản mặc định và không mở đăng ký công khai. Chỉ tài khoản tạo qua npm run admin:create mới đăng nhập được vào trang quản trị.
2

Cấu hình sản phẩm & kịch bản từ khóa

  1. Mở caidat.html và đăng nhập bằng tài khoản quản trị.
  2. Cập nhật tên cửa hàng, SĐT/địa chỉ công khai và câu trả lời mặc định của bot.
  3. Thêm hoặc chỉnh sửa sản phẩm (giá VND nguyên). Để ngừng bán món đã từng có đơn, chuyển trạng thái sang Đang ẩn hoặc Lưu trữ để giữ nguyên lịch sử đơn cũ.
  4. Cấu hình bảng từ khóa theo thứ tự ưu tiên (priority nhỏ hơn chạy trước).
3

Nhận và xử lý đơn hàng COD

  1. Khách chọn món trên index.html và gửi đơn COD. Máy chủ kiểm tra giá từ database, chống gửi trùng bằng Idempotency-Key và cấp mã đơn MN-....
  2. Đơn mới ở trạng thái Mới với phí vận chuyển chưa chốt.
  3. Chủ shop mở admin.html, gọi điện xác nhận với khách, nhập phí vận chuyển (VND) và chuyển đơn sang Đã xác nhận → Đang chuẩn bị → Đang giao → Hoàn tất.
4

Lộ trình mở rộng tiếp theo (M2 / M3)

  • M2 — Web chat & Inbox dùng chung: lưu hội thoại giữa khách và chủ shop trên database.
  • M3 — Tích hợp kênh ngoài (Messenger / Zalo OA): kết nối qua backend webhook có xác minh chữ ký và lưu token trong secret manager (tuyệt đối không nhúng token vào mã frontend).
